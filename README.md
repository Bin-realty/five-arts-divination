# 五術合一占卜台

塔羅、易經金錢卦、奇門遁甲、梅花易數交叉占卜，加上命盤與流年運勢的指令產生器。整個網站就是一個 `index.html`，不需要建置。

- 網站：https://bin-realty.github.io/five-arts-divination/
- 原始版本：阿正在 claude.ai 做的 Artifact「五術合一占卜台」

## 三個分區

| 分區 | 頁面做什麼 | 解讀方式 |
|---|---|---|
| 占卜區 | 排好塔羅、六爻、奇門盤、梅花卦 | 複製指令貼到任何 Claude 對話 |
| 命盤區 | 排好八字（四柱、十神、藏干、納音、大運） | 八字可直接解讀；占星與紫微需要 astrology-master 技能 |
| 流年運勢區 | 排好目前大運、流年、流月 | 同上 |

在 claude.ai 的 Artifact 裡開啟時，占卜區多一個「直接解讀」，會在頁面內呼叫 Claude；在 GitHub Pages 上這一區會自動隱藏。

## 怎麼一起改

1. 改 `index.html`（可以直接在 GitHub 網頁上按鉛筆編輯，或 clone 下來改）。
2. 小改直接推到 `main`；大改開一個分支發 Pull Request，讓對方看過再合併。
3. 推到 `main` 後約一分鐘，網站會自動更新。

本機預覽：任何靜態伺服器都可以，例如 `npx serve .` 後開 http://localhost:3000 。直接雙擊 `index.html` 也能看，但部分瀏覽器會擋本機檔案的儲存功能。

## 改程式前要知道的

- **牌庫順序不要動**：`DECK` 的順序（大牌 0–21，接著權杖、聖杯、寶劍、錢幣）決定定局抽到哪張；改了，同一個問題會抽到不同的牌。
- **定局的種子**：奇門局＋生辰（有填出生日期才算性別）＋正規化後的問題文字（去掉空白與標點、全半形統一）。改 `QM.seedString` 或 `QM.normQ` 都會讓既有結果改變。
- **和技能腳本同源**：`QM` 的奇門、梅花、定局算法和 astrology-master 技能的 `scripts/qimen.py`、`meihua.py`、`draw.py` 是同一套。占卜區的指令已不需要跑腳本，但兩邊若要繼續對照，2026-11 這版改了三處要同步：問題文字正規化、沒填生辰時不算性別、23 點後梅花易數改用隔天的農曆日期（和奇門日柱一致）。
- **外部資源**：Tailwind（cdn.tailwindcss.com）、lunar-javascript（cdn.jsdelivr.net）、Noto Serif TC（Google Fonts）。曆法程式載不到時，頁面會提示並改用純隨機。
- **存在瀏覽器的資料**（localStorage）：`fiveArtsUserProfile`（出生資料）、`fiveArtsDivination`（這次占卜）、`fiveArtsSystems`、`fiveArtsLockMode`、`fiveArtsTab`。頁尾「清除本機資料」會全部刪掉。

## 2026-11 這版改了什麼

- 占卜指令不再依賴本機腳本，牌、卦、盤與卦辭都寫進指令，貼到任何 Claude 都能解讀
- 命盤、流年在頁面直接排八字；占星與紫微沒有腳本時，要求 Claude 明說無法解讀，不要憑印象推算
- 問題文字正規化（多一個問號或空白不會換一組牌）；沒填生辰時不再把性別算進定局
- 定局後改了問題、生辰或定局方式會提醒重新定局；已抽牌時重新定局要按兩次
- 23 點後梅花易數的農曆日期和奇門日柱一致
- 重新整理後保留這次占卜；頁尾加免責說明與「清除本機資料」
- 頁面顯示卦辭與互卦卦序；沒有動爻時不再顯示和本卦相同的「變卦」
- 小牌加英文名，「皇后 (Queen)」改「王后」避免和大牌同名；第 14 卦卦辭補字「如日中天」
- 只填一個梅花數字時提示改用時間起卦；出生地點可自填經緯度與時區；日期欄加上範圍
- 複製失敗時退回 execCommand，手機改提示長按
- 只剩一個系統時改成單欄、區塊編號依顯示重新排；輔助文字提高對比；標題不再斷在詞中間
